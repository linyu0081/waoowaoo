# 宫格分镜方案可行性分析 v2

## 背景问题

单张分镜图逐张生成时，角色外貌/服饰/场景细节在不同图之间不一致的概率很高。
因为每次生图是独立推理，即使使用相同的角色参考图 + 提示词，模型也会产生不同的"诠释"。

## 宫格方案核心思路

将同一片段（Clip）的多个分镜合并成一张宫格图（Grid），在**一次生图推理**中同时生成所有镜头，
利用**同一张图内的上下文共享**来强制保持一致性。

## 核心约束条件

### 约束1：Seedance 单视频最长 15 秒
- 每个镜头对应一段 ≤15s 的视频
- 拆镜原则：**按 15s 为上限倒推镜头数**
- 一个 Clip 总时长 ÷ 15s = 最少镜头数（向上取整）
- 示例：60s 的 Clip → 至少 4 个镜头，每个 ≤15s

### 约束2：空间位置一致性
- **同一场景中，人物与所有内容物品的相对位置在各镜头间保持不变**
- 角色A在祭坛左侧（B位），角色B在祭坛右侧（C位），则所有镜头中A、B的位置关系不变
- 除非剧情明确描述了位置移动（如"赵玄真退后半步"），否则默认位置锁定
- 宫格提示词中每格必须标注角色所在的场景位置标识（A/B/C...）

### 约束3：美术风格一致性
- 宫格图必须与角色参考图、场景参考图的美术风格完全一致
- 提示词中强制追加：「保持与参考图片美术风格一致」
- 使用 --input-images 传入角色参考图 + 场景参考图，确保风格锚定

### 宫格规格（基于15s限制）

| Clip时长估算 | 镜头数（≤15s/个） | 推荐宫格 | 说明 |
|-------------|-----------------|---------|------|
| ≤45s        | 3-5             | 3×2 或 3×3 | 留空格无影响 |
| 46-75s      | 4-7             | 3×3     | 最多9格 |
| 76-120s     | 6-10            | 4×3 或 4×4 | 最多16格 |
| 121-180s    | 9-14            | 4×4     | 最多16格 |
| >180s       | 13+             | 拆为多张宫格 | 每张≤16格 |

## 宫格提示词模板 v2

```
生成一张{rows}×{cols}宫格分镜图，{artStylePrompt}。保持与参考图片美术风格一致。

角色参考：@图片1 是{角色A名}（{角色A外貌简述}），@图片2 是{角色B名}（{角色B外貌简述}），@图片3 是场景参考（{场景名}）。

场景位置参考：A位-{位置A描述}，B位-{位置B描述}，C位-{位置C描述}...

按从左到右、从上到下的顺序，每格内容如下：
格1（第1行第1列）：{镜头1的画面描述}。{角色A}在{X}位，{角色B}在{Y}位。
格2（第1行第2列）：{镜头2的画面描述}。{角色A}在{X}位，{角色B}在{Y}位。
...
格N（第{rows}行第{cols}列）：{镜头N的画面描述}。位置同上。

要求：
- 所有格中同一角色的外貌、服饰、体型必须完全一致
- 空间中人物与所有内容物品的相对位置在各格之间保持不变（除非剧情明确移动）
- 保持与参考图片美术风格一致
- 每格之间用细白线分隔
- 每格内画面完整，不被分割线切断
- 保持电影级画面质量
```

## 视频生成流程 v2（宫格图直接作参考）

### 核心变更：宫格图不放大/不切分，直接作为视频生成的参考图

```
Step 1: 分镜师完成 4 阶段分镜 → 输出每个镜头的 video_prompt
Step 2: 按 Clip 生成宫格分镜图（1张/Clip）
Step 3: 上传宫格分镜图、角色参考图、场景参考图到 CDN
Step 4: 逐镜头生成视频，每个镜头的 reference-assets 包含：
        - 角色参考图（@图片1、@图片2...）
        - 场景参考图（@图片N）
        - 宫格分镜图（@图片N+1）← 新增！作为整体分镜参考
Step 5: video_prompt 格式：
        "@图片1 是{角色A}，@图片2 是{角色B}，@图片3 是场景参考，
         @图片4 是分镜参考图（参考其中第X格的构图和画面）。
         {具体剧情描述}。{主体动作}。{环境描述}。{镜头语言}。"
```

### video_prompt 模板 v2

```
@图片1 是{年龄段+性别A}，@图片2 是{年龄段+性别B}，
@图片3 是{场景名}场景参考，@图片4 是本片段分镜参考图。

参考@图片4中第{N}格的构图。
{具体剧情}：{一句话描述当前镜头发生的事}。
{主体动作}：{角色的具体动作描述}。
{环境}：{场景环境+光影氛围}。
{镜头语言}：{景别}，{机位}，{运镜方式}。

{artStylePrompt}
```

### 优势对比

| 维度 | 旧方案（逐张分镜图） | 新方案（宫格直接参考） |
|------|-------------------|---------------------|
| 角色一致性 | ⭐⭐ 低 | ⭐⭐⭐⭐ 高（宫格内统一） |
| 场景一致性 | ⭐⭐ 低 | ⭐⭐⭐⭐ 高 |
| 位置一致性 | ⭐⭐ 无约束 | ⭐⭐⭐⭐ 标注位置锁定 |
| 调用次数 | N(分镜图) + N(视频) | 1(宫格) + N(视频) |
| 放大步骤 | 需要 | **不需要**（直接参考） |
| 总效率 | 2N 次 | N+1 次（减半） |

## 风险与对策

| 风险 | 说明 | 对策 |
|------|------|------|
| 宫格图作参考时模型理解不准 | 模型可能无法准确定位"第N格" | prompt 中明确描述格子位置+格内内容 |
| 宫格格数过多导致每格细节不足 | 16格时每格较小 | 优先 3×3，超过则拆为多张宫格 |
| 位置标识在分镜中丢失 | 模型忽略A/B/C站位 | 每格提示词中显式写出"角色在X位" |
| 美术风格漂移 | 视频与参考图风格不一致 | prompt 末尾强制追加风格锚定描述 |

## 执行策略（推荐）

1. **分镜师阶段**：4 阶段分镜 + 每镜头标注角色位置（A/B/C）+ 时长预估（≤15s）
2. **宫格生图**：每 Clip 一张宫格，上传角色图+场景图作 input-images
3. **视频生成**：每镜头的 reference-assets = [角色图, 场景图, 宫格分镜图]，prompt 中 @引用全部 + 写清剧情/动作/环境/镜头语言
4. **不放大、不切分**：宫格图直接传给 Seedance 做整体参考

---

**结论：方案可行且更优。相比 v1 减少了放大步骤，调用次数减半，同时通过位置标识和美术风格锚定进一步提升一致性。**
