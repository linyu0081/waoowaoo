# 宫格分镜图生成规范

[目的]
    将同一 Clip 的多个分镜合并成一张宫格图（Grid），在一次生图推理中同时生成，
    利用同一张图内的上下文共享来强制保持角色/场景/站位的一致性。

[数据来源]
    所有宫格提示词的信息必须从 03-storyboard.json 提取，包括：
    - description：画面描述
    - shot_type：景别
    - camera_move：运镜（宫格图中体现为构图角度）
    - characters[].slot：⚠️ 人物站位位置（必须标注）
    - photography.lighting：光线方向和质感
    - photography.depth_of_field：景深
    - photography.color_tone：色调
    - acting_notes[].acting：角色表演细节

[提示词模板]

    ```
    生成一张{rows}×{cols}宫格分镜图，{artStylePrompt}。保持与参考图片美术风格一致。

    角色参考：@图片1 是{角色A名}，@图片2 是{角色B名}，@图片3 是场景参考（{场景名}）。

    场景位置参考：
    A位-{位置A描述}，B位-{位置B描述}，C位-{位置C描述}，D位-{位置D描述}

    按从左到右、从上到下的顺序，每格内容如下：

    格1（第1行第1列）：{shot_type}，{description详写}。
    {角色A}在{X}位{acting描述}。
    光线：{lighting.direction}，{lighting.quality}。
    景深：{depth_of_field}。色调：{color_tone}。

    格2（第1行第2列）：...
    ...

    要求：
    - 所有格中同一角色的外貌、服饰、体型必须完全一致
    - 空间中人物与所有内容物品的相对位置在各格之间保持不变（除非剧情明确移动）
    - 保持与参考图片美术风格一致
    - 每格之间用细白线分隔
    - 每格内画面完整，不被分割线切断
    - 保持电影级画面质量
    - 禁止输出任何描述文字
    ```

[每格必须包含的信息（缺一不可）]

    1. 景别（shot_type）：如"平视近景"、"仰拍全景"、"俯拍大远景"
    2. 画面描述（description）：核心视觉内容
    3. 人物站位（characters[].slot）：如"安倍宗介在A位（祭坛正前方）"
       ⚠️ 即使角色在该格中是近景/特写，也要标注其在场景中的位置
       无人物的空镜/特效镜头标注"无人物"
    4. 表演细节（acting_notes）：如"嘴角上扬冷笑、双眼微眯、右手蝙蝠扇前指"
    5. 摄影参数三件套：
       - 光线（lighting）：方向+质感，如"侧光从左照入，冷调侧光半明半暗"
       - 景深（depth_of_field）：如"浅景深T2.8聚焦面部"
       - 色调（color_tone）：如"暗沉冷调，暗红青灰为主"
    6. 无参考图的元素外貌描写：如式神、八岐大蛇等需用文字描述

[场景位置标识系统]
    从 03-storyboard.json 的 characters[].slot 提取，建立位置坐标：
    
    示例（明孝陵地下陵宫）：
    A位 = 祭坛正前方与石壁之间的空地（安倍宗介默认位置）
    B位 = 祭坛左侧
    C位 = 祭坛右侧
    D位 = 陵宫入口石门内侧（赵玄真入场位置）
    
    规则：
    - 同一角色在不同格中，除非剧情明确移动，否则位置锁定
    - 每格提示词显式标注"角色在X位"
    - 位置关系在宫格提示词开头统一声明

[宫格规格选择]
    | 格数 | 推荐宫格 | 适用 |
    |------|---------|------|
    | 3-5格 | 3×2 | 少量分镜 |
    | 6-9格 | 3×3 | 标准（推荐） |
    | 10-12格 | 4×3 | 较多分镜 |
    | 13-16格 | 4×4 | 最大（不推荐超过） |
    | >16格 | 拆为多张 | 每张≤16格 |

[生成参数]
    - model: 314（zencli generate image）
    - aspect-ratio: 16:9
    - resolution: 1（2K 1920×1080）
    - input-images: 角色参考图 + 场景参考图（用逗号分隔URL）
    - 建议每次生成2张供挑选

[宫格图后续使用]
    生成后的选择流程：
    
    Step 1: 用户审查宫格图
        - 用户查看生成的宫格图，评估每个格子的画面质量
        - 满意的格子 → 单独切分放大为 panel-XX-from-{版本}.jpg
        - 不满意的格子 → 不做任何切分操作

    Step 2: 满意度自动判断
        AI视频导演通过扫描 outputs/<集数>/images/ 目录自动判断：
        - 存在 panel-XX-from-*.jpg → status: "adopted"（已采用）
        - 不存在对应文件 → status: "text_only"（不满意/未采用）

    Step 3: 根据状态决定引用策略
    
        ✅ adopted 的 panel：
            方式A（推荐）：直接作为视频参考图
                - 宫格图整张或切分后的独立图传入视频生成的 reference-assets
                - prompt 中用"参考@图片N"引用
            
            方式B：AI放大为独立分镜图
                - 用 zencli generate image 放大指定格子
                - 放大提示词：'这是一张{rows}x{cols}宫格分镜图，请将第{行}行第{列}格的画面
                  单独放大为一张完整的高清图片。该格子是：{格子描述}。
                  保持原有风格和细节，放大至高清。禁止输出任何描述文字'
                - 放大后保存为 panel-XX-from-{版本}.jpg
        
        ❌ text_only 的 panel：
            - 不引用任何分镜图
            - AI视频导演在生成提示词时，用导演级详细文字描写替代参考图：
              · 完整的角色外貌、服饰、体型描写
              · 精确的空间站位和场景元素位置关系
              · 摄影参数（光线、色调、景深）融入场景描写
              · 法器/道具/特效详细外观描写（50+字）
            - 这种纯文字方案让模型完全依赖提示词理解画面，
              避免了不满意的参考图反而干扰模型生成质量的问题
