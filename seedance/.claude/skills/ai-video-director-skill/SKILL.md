# AI视频导演技能包

[技能说明]
    本技能包为 ai-video-director agent 提供：
    1. 视频分段规划方法（含精确时长估算）
    2. 已有资产引用分析逻辑
    3. Seedance 提示词生成规范

    提示词方法论详见：video-production-skill/seedance-prompt-methodology.md
    提示词组装规则详见：video-production-skill/SKILL.md

[Phase 1: 视频分段规划]

    [时长估算模型]

        ★ 核心原则：不沿用分镜师的 duration_sec，根据实际内容精确计算。

        1. 台词朗读时长

            计算公式：台词时长 = 台词字数 ÷ 语速 + 话轮停顿

            语速参考表：
            | 语速类型 | 字/秒 | 适用场景 |
            |---------|-------|---------|
            | 正常语速 | 3-4 | 日常对话、叙述、解说 |
            | 激动/快语 | 5-6 | 争吵、激动、紧急、怒喝 |
            | 缓慢/低语 | 2 | 独白、低沉、犹豫、自言自语、临终遗言 |

            语速判断依据：
            - 从 panel 的 acting_notes / source_text 推断角色情绪状态
            - 台词含"！"、多个感叹号 → 偏激动
            - 台词含"……"、自嘲、独白标记 → 偏缓慢
            - 正常对话、陈述 → 正常语速

            话轮切换：每次换人说话加 0.5-1 秒
            - 对抗性对话（怒喝→反驳）：0.5s
            - 正常对话轮次：0.8s
            - 沉默后开口：1.0s

        2. 动作时长

            统计 panel description / video_prompt 中的主要物理动作：
            | 动作类型 | 秒/动作 | 示例 |
            |---------|---------|------|
            | 简单动作 | 2.0 | 转头、抬手、点头、微笑 |
            | 中等动作 | 2.5 | 释放法术、拔剑、扔物品、展开符箓 |
            | 复杂动作 | 3.0+ | 打斗序列、追逐、大范围运镜、爆炸 |
            | 纯反应 | 1.5-2.0 | 震惊、沉默凝视、咬牙 |

        3. 安全区
            头尾安全区 = 1 秒（前 0.5s 画面建立 + 后 0.5s 画面稳定）

        4. 总时长公式
            单 panel 时长 = max(台词时长 + 停顿, 动作时长) + 安全区(1s)
            
            注意：台词和动作可以重叠（角色边说边做），所以取 max 而非相加

        5. 示例
            Panel: 安倍宗介说「抽干了这龙魂，引大和皇魂入主此地，从此，这片土地将臣服于我！」
            - 台词27字，情绪：嚣张激动 → 5字/秒 → 27/5 = 5.4s
            - 动作：嘴角冷笑(简单) → 2s
            - max(5.4, 2) + 1 = 6.4s → 取 7s（向上取整到整数）

    [分段规则]

        核心原则：尽量贴满15s，最大化段内一致性，减少总段数。

        1. 按 panel 顺序依次累加重估时长
        2. ⚠️ 分段规划时以15秒为目标上限，允许略超（如16s、18s因连续动作不可拆）
           但调用视频生成接口时 duration 参数最大传 15（平台硬限制），
           让模型在15s内自行压缩节奏完成内容
        3. 当累计超过 15 秒时，在上一个 panel 处切断，开始新段
        3. ⚠️ 硬切不强制分段！
           - 硬切的 panel 可以和前面的 panel 合并在同一段
           - 硬切在提示词中用转场描述体现（"镜头硬切至..."），而非物理分段
           - 目的：减少短段，每段尽量接近 12-15s
        4. 只在 Clip 边界（clip_id 变化）才强制分段
        5. 单个 panel 台词超长（>15s）时独占一段，规划时长允许略超但接口传15s
        6. 合并优先级：
           a) 非硬切连续动作 → 优先合并
           b) 硬切但剧情连贯（如反应→新事件）→ 可合并
           c) 正反打对话 → 多轮可合并为一段

        段内硬切提示词写法：
            当段内某panel的 connect_camera_move 为"硬切"时，在提示词中这样衔接：
            "...{前段剧情描述}。镜头硬切至——{后段剧情描述}..."
            示例："蛇身膨胀，参考@图片4。镜头硬切至——五枚泛着铜绿光芒的古老铜钱从画面左侧破空飞来..."

    [输出格式]
        Phase 1 输出为内部中间数据（不直接写入文件），供 Phase 2/3 使用：
        {
          "segments": [
            {
              "segment_id": "SEG-01",
              "panels": [1, 2],
              "estimated_duration_sec": 10,
              "duration_breakdown": {
                "panel_1": { "speech_sec": 0, "action_sec": 4, "safety_sec": 1, "total": 5 },
                "panel_2": { "speech_sec": 0, "action_sec": 4, "safety_sec": 1, "total": 5 }
              },
              "cut_reason": "Panel 3 connect=缓缓推近 但累计超15s"
            }
          ]
        }

[Phase 2: 已有资产引用分析]

    [目的]
        检查每个 segment 可引用哪些已有资产，不额外生图。
        重点解决跨段视觉一致性问题。

    [引用类型]

        类型A：固定资产（每段按需引用）
            - 角色参考图：char-XXX.png → 该角色出现的段落引用
            - 场景参考图：scene-XXX.png → 该场景的段落引用

        类型B：分镜图复用（跨段引用关键构图）
            检查逻辑：
            1. 遍历每个 segment 的剧情内容
            2. 如果本段涉及的视觉元素在之前的分镜图中有过清晰呈现，则引用之
            3. 常见复用场景：
               - 同一场景不同时刻 → 引用建立镜头的全景分镜图
               - 角色站位需要一致 → 引用之前展示站位的分镜图
               - 元素再次出现（如蛇被砍后再生）→ 引用该元素首次清晰出现的分镜图
               - 法器/道具特写反复出现 → 引用首次特写的分镜图

            ⚠️ 分镜图满意度判断（⭐ 核心规则）：
            只有被用户「单独切分放大」并保存为 panel-XX-from-*.jpg 的分镜图才视为已采用。
            判断方法：扫描 outputs/<集数>/images/ 目录，检查是否存在对应 panel 的独立文件。

            - 存在 panel-XX-from-*.jpg → ✅ 已采用，可在提示词中引用为 @图片N
            - 不存在对应文件 → ❌ 未采用/不满意，提示词中 **不引用该分镜图**，
              改为纯文字详细描写该 panel 的画面内容，包括：
              · 完整的角色外貌、服饰、体型描写
              · 精确的空间站位和场景元素位置关系
              · 光影方向、色调、氛围
              · 法器/道具/特效的详细外观描写
              · 运镜起止构图

            文字补完原则：
            - 用导演级详细描写替代参考图的视觉锚定作用
            - 从 03-storyboard.json 提取 description、acting_notes、photography 等全量信息
            - 对无参考图的元素（式神、法器、特效等），必须用 50+ 字详细描写外观形态
            - 角色服饰/体型描写需与已有的角色参考图描述保持一致（从 characters.json 获取）

        类型C：段间衔接帧（动态填充）
            - connect_camera_move 非硬切的段 → 标记需要上段末帧
            - 实际提取在 video-director 执行生成时完成（ffmpeg -sseof -1 -frames:v 1）
            - 在 reference_images 中预留占位："@图片N": "上段末帧（生成后自动填入）"

    [输出格式]
        为每段补充 reference_images 和 reference_notes：
        {
          "reference_images": ["@图片1", "@图片4", "@图片5"],
          "reference_notes": {
            "@图片1": "安倍宗介人物形象参考",
            "@图片4": "陵宫场景参考",
            "@图片5": "复用Panel-01全景构图，锚定站位和环境"
          },
          "text_only_panels": [10, 11],
          "text_only_reason": "Panel-10/11无已采用分镜图，用文字详写替代"
        }

[Phase 3: 提示词生成]

    [遵循规范]
        ★ 必读：video-production-skill/seedance-prompt-methodology.md
        ★ 必读：video-production-skill/SKILL.md 的提示词组装规则

    [提示词组装顺序]
        1. 角色引用 + 声线（⚠️ 只引用本段画面中实际出镜的角色参考图）
        2. 场景引用
        3. 关键帧统一引用（⭐ 新规则：所有关键帧在正文之前统一声明）
        4. 段间衔接引用（非硬切时）
        5. 正文剧情（详细扩写，含运镜+动作+光影+音效）
        6. 段内硬切（"镜头硬切至——"）
        7. 画外音（未出镜角色台词）
        8. 摄影参数 + 体积光标签（强制）
        9. 风格后缀 + 画面质量后缀

    [关键帧前置统一引用规则（⭐ 核心变更）]
        所有关键帧不再散落在剧情描述中，而是在正文开始前统一声明：
        格式："{景别}·{内容简述}参考@图片N"
        
        示例（有分镜图）：
            以@图片1中的安倍宗介（男声，中年音色，阴冷嚣张带日式口音）为主角参考，
            场景参考@图片4的明孝陵地下陵宫，
            平视中景·安倍宗介站位参考@图片6，
            安倍宗介面部近景·阴鸷冷笑参考@图片7。
            （空行后开始正文）
        
        示例（无分镜图 — 纯文字替代）：
            以@图片1中的安倍宗介（男声，中年音色，阴冷嚣张带日式口音）为主角参考，
            @图片2中的赵玄真（男声，老年音色，苍劲浑厚）为角色参考，
            场景参考@图片4的明孝陵地下陵宫。
            （无分镜图的 panel 不声明关键帧引用，在正文中用详细文字描写替代）
            （空行后开始正文）
        
        规则：
        - 每个关键帧独占一行，用"景别·内容"简述其构图意图
        - 排列顺序按 panel 先后
        - 正文中不再重复"参考@图片N"或"最后定格于@图片N"
        - ⚠️ 仅引用已采用的分镜图（存在 panel-XX-from-*.jpg 的），
          未采用的 panel 不声明关键帧引用，其画面内容在正文分时段描述中用详细文字补完

    [方法论驱动的详细扩写（⭐ 核心变更）]
        AI视频导演在编写提示词时，必须参考 seedance-prompt-methodology.md 中的
        分类型写作方法论，根据每段视频的内容类型，补充该类型的关键要素：

        ⚠️ 分时段描述的时间范围上限 = 15秒：
        - 即使规划时长略超15s（如16s、18s），提示词中的分时段描述也必须写到15秒为止
        - 例：规划18s的段 → 分时段写 0-5s / 5-10s / 10-15s（不写10-18s）
        - 接口调用 duration 也传15，模型在15s内自行压缩节奏

        类型判断与关键要素植入：
        | 内容类型 | 对应方法论 | 必须植入的关键要素 |
        |---------|-----------|------------------|
        | 战斗/法术 | 类型1+5 | 速度感词汇、物理反馈（碎石飞溅/地面炸裂）、能量特效（色彩+形态+运动）、打击音效 |
        | 对话/对峙 | 类型4 | 微表情变化层次（从X到Y）、情绪节奏留白、浅景深/焦点转移 |
        | 建立镜头/空镜 | 类型5 | 宏大环境规模、丁达尔光/体积光、色彩方案、氛围音效 |
        | 情感/独白 | 类型4+7 | 环境细节烘托、色温指定、极缓镜头运动 |
        | 觉醒/召唤 | 类型2+5 | 分阶段变化过程、能量汇聚扩散、声效描写 |

        扩写原则：
        - 将分镜师的 sync_video_prompt（简要描述）扩展为导演级详细提示词
        - 补充物理反馈描写（如"铁链钉入龙鳞，金色鳞片剥落漫天飞舞如流星坠落"）
        - 补充光影变化（如"勾玉绿光映照石壁，安倍宗介面部半明半暗"）
        - 补充音效设计（如"金属锁链碰撞声、龙的哀鸣回荡石室"）
        - 补充环境互动（如"震颤导致石块从穹顶掉落，灰尘弥漫"）
        - 10秒以上推荐使用分时段描述（0-5s / 5-10s / 10-15s）

    [摄影参数植入（强制）]
        每段提示词正文结尾、画面质量后缀之前，必须植入摄影参数：
        
        格式："电影级真实画质，{色调}，{景深}，{光线}"
        
        参数来源：03-storyboard.json 中每个 panel 的 photography 字段
        - color_tone → 色调描述
        - depth_of_field → 景深描述
        - lighting → 光线描述
        
        多 panel 合并时，取主要 panel 的摄影参数，或描述光线变化过程。
        
        示例：
        "电影级真实画质，暗沉冷调以暗红青灰为主，浅景深背景虚化，
        侧光从左侧照入面部半明半暗。"

    [体积光标签植入（强制）]
        每段提示词中必须包含至少一个体积光/光效描写：
        
        常用标签（根据场景选取）：
        - 丁达尔光穿透（适用于有光源穿透的场景）
        - 体积光雾气弥漫（适用于昏暗/神秘场景）
        - 能量光芒四射（适用于法术/觉醒场景）
        - 逆光剪影（适用于入场/建立镜头）
        - 火光映照（适用于有火焰/爆炸场景）
        - 月光/星光倾泻（适用于夜景）
        
        植入位置：融入场景描述或光影描写中，不要生硬堆砌。
        示例："祭坛上鲜血散发暗红微光，体积光雾气在石室中弥漫流转"

    [画外音规则]
        当角色有台词但未在本段视频画面中出镜时：
        - ❌ 不引用该角色的参考图
        - ✅ 用画外音格式："画外音{情绪}道（{voiceLine}）：「{台词}」"
        
        判断标准：panel 的 characters 数组中不含该角色 → 画外音

    [跨段复用引用的自然语言写法]
        不是生硬地"参考@图片N"，而是融入叙事：
        - "背景中金色神龙被锁链缠绕（参考@图片9的龙身构图）"
        - "陵宫全貌与@图片5一致，安倍宗介站在祭坛前原位"
        - "蛇身再生膨胀，体型参考@图片9中被锁链缠绕的规模"

[节奏风格配置]

    项目配置 Q4 的节奏风格影响 Phase 1 的非台词段时长：

    | 节奏 | 空镜/建立镜头 | 反应镜头 | 运镜留白 |
    |------|-------------|---------|---------|
    | 标准节奏（默认）| 3s | 2s | 适中 |
    | 快节奏 | 2s | 1.5s | 紧凑 |
    | 电影节奏 | 4-5s | 3s | 舒缓 |

    ⚠️ 台词时长不受节奏风格影响，始终按实际语速计算。
    节奏风格只影响：空镜时长、反应镜头时长、无台词动作段的节奏感。
