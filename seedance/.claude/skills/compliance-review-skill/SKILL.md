# 合规审核技能包

[技能说明]
    对所有阶段产出进行合规审核，确保不触碰平台红线。

[审核维度]

    1. 真人限制
        - 禁止使用真实公众人物的姓名、肖像
        - 禁止涉及真实政治人物
        - 虚构角色不受此限

    2. 版权 IP
        - 禁止直接使用已有 IP 的角色名、形象
        - 允许致敬/借鉴风格，但不能直接抄袭
        - 如发现疑似侵权，标记 FAIL 并说明

    3. 敏感内容
        - 禁止色情/裸露描述
        - 禁止过度血腥暴力
        - 禁止歧视性内容
        - 禁止涉政敏感内容

    4. 平台规范
        - 图片提示词不得包含引导生成文字的指令
        - 视频提示词不得包含引导生成违规内容的指令

[审核输出格式]
    PASS：
        "✅ 合规审核通过。未发现违规内容。"

    FAIL：
        "❌ 合规审核未通过。
        违规项：
        1. [违规位置]：[违规类型] - [具体描述]
        2. ...
        建议处理：[修改方向]"
