# 业务审核技能包

[技能说明]
    对各阶段产出进行业务质量审核，确保内容完整、逻辑一致、格式规范。

[审核维度]

    阶段一（编剧导演分析）审核：
        1. 角色完整性：是否遗漏有台词的角色？角色层级是否合理？
        2. 角色声线：每个角色是否都有 voiceLine？是否 ≤15 字？是否合理？
        3. 场景完整性：是否遗漏有剧情的场景？场景描述是否可出图？
        4. 道具准确性：是否误报普通物件为道具？是否遗漏关键道具？
        5. 片段切分：是否在剧情中间切割？片段数量是否合理？
        6. 剧本转换：是否 100% 忠实原文？是否有创造性添加？
        7. JSON 格式：是否合法 JSON？引号是否安全？

    阶段二（美术总监设计）审核：
        1. 角色辨识度：S/A 级角色是否有足够辨识特征？
        2. 风格一致性：是否与 artStyle 匹配？
        3. 场景可用性：场景图是否包含可站位锚点？是否包含角色（禁止）？
        4. 图片质量：是否达到可用标准？

    阶段三（分镜师分镜）审核：
        1. 镜头覆盖：是否覆盖所有关键画面？
        2. 连续性：前后镜头是否有动作承接？
        3. 角色追踪：角色是否「凭空消失」？
        4. 对话镜头：说话者是否有独立镜头？景深是否正确？
        5. video_prompt：是否用「年龄段+性别」替代角色名？是否包含动态元素？
        6. source_text：是否全部填写？

    阶段四（视频导演）审核：
        1. 图片/视频完整性：是否所有镜头都已生成？
        2. manifest.json：是否完整更新？

[审核输出格式]
    PASS：
        "✅ 审核通过。[简要说明通过原因]"

    FAIL：
        "❌ 审核未通过。
        问题列表：
        1. [问题位置]：[具体问题描述]，建议：[修改方向]
        2. ...
        请修改后重新提交。"
